## Funcionalidades

- ✅ Arquivo principal (`index.html`) exibindo um roteiro de aprendizado (roadmap) por ordem cronológica. Do mais antigo pro mais novo
- ✅ Explicação detalhada de cada tópico (conteúdo aprofundado, dividido em seções)
- ✅ HTML + Tailwind CSS (via CDN) + JavaScript puro (vanilla)
- ✅ Arquivo HTML dedicado para cada tópico (`topics/*.html`)
- ✅ Barra lateral compartilhada para navegação entre tópicos (injetada via JS, com navegação anterior/próximo)
- ✅ Diagramas Mermaid em todas as páginas explicando o funcionamento de cada tópico
- ✅ Página de referências (`references.html`) listando livros, cursos, vídeos, artigos e documentação por tópico
- ✅ Crie uma memória do que foi implementado em uma pasta (`memory`) com arquivos do tipo markdown para cada tópico

## Tech stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript (no framework)
- Mermaid 11 (ESM CDN) para diagramas
